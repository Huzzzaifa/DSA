# DSA Playground

A small, dependency-free Python project for exploring common data structures
and algorithms.

## Included

- **Stack** and **Queue** — basic last-in, first-out and first-in, first-out
  data structures.
- **Binary search** — finds a value in a sorted list in `O(log n)` time.
- **Merge sort** — sorts a list in `O(n log n)` time.
- **Breadth-first search** — finds a shortest path in an unweighted graph.

## Run the demo

From this directory, run:

```bash
python dsa_playground.py
```

## Run the tests

```bash
python -m unittest -v
```

Only the Python standard library is needed.
